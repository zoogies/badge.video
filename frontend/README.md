# badge.video frontend

Static, offline-first dashboard for the compact data generated by the scraper.

From `scrapers`:

```powershell
uv run pipeline.py site-data
```

From this folder:

```powershell
python -m http.server 5173
```

Open:

```text
http://localhost:5173
```

The first version uses only classified videos and prebuilt JSON under `public/data`.
